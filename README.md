# Education Practice & Evidence Portfolio — Adesh Kumar Mishra

A single-page portfolio that combines a case study of building a 14-centre education practice with an evidence study on diagnostic gaps in programme management.

🌐 **Live page:** https://adeshmishra52.github.io/IBM-Portfolio/ *(served by GitHub Pages from `index.html`)*

## What's inside

- **Flagship case study:** scaling a 14-centre education practice (1,500+ learners/year). It covers curriculum architecture, building an LMS from scratch (+25% online enrolment) and topic-level diagnostics (~15% YoY pass-rate improvement).
- **Evidence research: *When Averages Mislead*.** Live data from 312 students across 14 Delhi NCR centres (JEE Main 2026, Session 1) led to four findings:
  1. **Mean–median trap:** a 9.9-point gap hides a struggling lower tail
  2. **Resource-allocation paradox:** Physics (r = 0.90) predicts outcomes better than Maths (r = 0.66)
  3. **Centre-level variance:** the same curriculum produces a 4× difference in JEE Advanced conversion
  4. **Recognition failure:** 35 students crossed the 99th percentile, but only 14 were recognised
